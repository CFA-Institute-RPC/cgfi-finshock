# CGFI Network Shock Model

The **CGFI Network Shock Model**, developed by the [CFA Institute Research & Policy Center (RPC)](https://rpc.cfainstitute.org/) in collaboration with the [UK Centre for Greening Finance and Investment (CGFI)](https://www.cgfi.ac.uk/), is an open-source platform designed to model systemic climate transition risks in interconnected financial systems. This tool enables policymakers, financial professionals, and researchers to analyze how risks propagate through financial networks under various climate scenarios.

---

## 🌟 Key Features
- **Systemic Risk Analysis**: Evaluate cascading effects of climate transition risks across financial institutions.
- **Scenario Testing**: Simulate diverse climate transition scenarios to assess vulnerabilities and potential impacts.
- **Open Collaboration**: Transparent codebase inviting contributions from a global community of finance and tech experts.
- **Live Demo**: Explore the tool in action with our [live demo](https://cfa-institute-rpc.github.io/cgfi-finshock/).

---

## 📚 Research Foundation
This tool is grounded in the research report ["Modeling Climate Transition Risk: A Network Approach"](https://rpc.cfainstitute.org/research/reports/2024/modeling-climate-transition-risk). Key highlights include:

1. **Identifying Vulnerable Nodes**: Pinpoint areas of high exposure in financial systems.
2. **Scenario-Based Stress Testing**: Model the propagation of transition risks through interconnected systems.
3. **Actionable Insights**: Provide recommendations for policymakers and investment professionals to mitigate systemic risks.

For a comprehensive understanding, read the full report [here](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4905653).

## 🚀 Getting Started

### Prerequisites
- Ensure you have `yarn` installed. For installation instructions, visit [Yarn Documentation](https://yarnpkg.com/getting-started/install).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/CFA-Institute-RPC/cgfi-finshock.git
   cd cgfi-finshock
   ```
2. Install dependencies:
   ```bash
   yarn install
   ```

### Building the Project
To build the project, run:
```bash
yarn run build
```
The output files will be located in the `/dist` directory.
